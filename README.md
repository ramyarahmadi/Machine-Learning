# Machine Learning & Data Science Projects

This repository is a collection of small, self-contained machine learning and data analysis projects. Each file explores a different problem, dataset, or technique. Below is an overview of what you'll find here.

## 📌 Recommender Systems

Projects that build recommendation engines using collaborative filtering, content-based filtering, and hybrid approaches.

- **IMDb Movie Recommender** — Suggests movies based on user ratings and content similarity (genre, cast, plot).
- **Spotify Music Recommender** — Recommends songs and playlists based on audio features and listening history.

## 💬 Review & Sentiment Analysis

Projects focused on analyzing customer reviews to extract sentiment, ratings, and insights using NLP techniques.

- **Digikala Reviews** — Sentiment analysis on product reviews from Digikala.
- **Snapfood Reviews** — Analyzing customer feedback and ratings for food delivery orders.
- **Amazon Reviews** — Text classification and sentiment scoring on Amazon product reviews.

## 📈 Regression Projects

Projects that apply regression models to predict continuous values and fit functions to data.

- **Bitcoin Price Estimation** — Predicting Bitcoin prices using historical data and regression models.
- **Sinusoidal Function Fitting** — Fitting different models (linear, polynomial, neural networks, etc.) to sinusoidal data to compare performance and accuracy.

## 🖼️ Image Classification

Projects that train and evaluate models to classify images across various datasets.

- Multiple image classification tasks using different datasets, exploring various architectures and techniques (CNNs, transfer learning, etc.).

## 📂 Repository Structure

Each project lives in its own file/folder with:
- The code/notebook for the project
- A short description of the goal and approach
- The dataset used (or a link/reference to it)
- Results and takeaways

## 🎯 Purpose

This repository serves as a personal playground for practicing and showcasing different machine learning techniques — from recommendation systems and NLP to regression and computer vision — using real-world and well-known datasets.

## 🛠️ Tech Stack

Common tools and libraries used across projects:
- Python
- Pandas, NumPy
- Scikit-learn
- TensorFlow / PyTorch
- Matplotlib, Seaborn
